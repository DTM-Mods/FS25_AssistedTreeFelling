## What it does

Drive up to a tree and a ring shows on the tree you can fell: yellow means in reach, green means the head is on the tree, red means too thick or not allowed.

- **Hold Q:** the crane swings to the tree, reaches in, lowers the head to the ground, cuts the tree and lifts it, ready to back out. Let go of Q to stop at any time.
- **O** (the game's own auto-aim key): aims only, so you can cut yourself.
- **Left Shift + Q:** centre the crane (folds it back to its start position and swings it straight ahead).

Multiplayer supported. See [PATCH_NOTES.md](PATCH_NOTES.md) for changes.
